# Outil-de-raccordement
Cet outil QGIS optimise les tracés de raccordement électrique vers les postes RTE. Il calcule le chemin le moins cher par Dijkstra, gère les forçages, les barrières et la proximité HTA (20 m). Il analyse l’impact foncier (public, privé, AFR/AFU) avec tolérance de micro-traversée (10 m), intègre le coût du câble et exporte plans et rapports.
